# 面向数据工作的开发工具

## 目录介绍

| dir  | description  |
| :--: | :----------: |
| bash | 终端配置项目 |
| pwsh | 终端配置项目 |
| bin  |   命令文件   |
| ofme | 个人开发项目 |
| ofai |  ai开发项目  |
| env  |   环境变量   |

## 项目使用

- **prs项目**
  该项目需要clone至$Home/core/
- **终端配置项目**
  根据具体工作环境选择其一，win环境使用pwsh、linux环境使用bash等

```powershell
    $HOME\core\prs\pwsh\init.ps1
```

```bash
    $HOME/core/prs/bash/init.sh
```
